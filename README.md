# ExamMaster Pro

Small Spring Boot app for allocating exam seats and exporting CSVs.

## Quick start

Prerequisites:
- Docker Desktop (or a Docker Engine reachable from CI)
- Java JDK 17+ (for local build)
- Maven (or use the included `mvnw`/`mvnw.cmd`)

Build and run the fat JAR locally:

```bash
./mvnw -DskipTests package
java -jar exammaster-pro/target/exammaster-pro-0.0.1-SNAPSHOT.jar
```

Build a container image using the Spring Boot Maven plugin (buildpacks):

```bash
# this uses the image name configured in pom.xml
./mvnw -DskipTests spring-boot:build-image

# verify image exists
docker images | grep exammaster-pro

# run the image (replace ports/env as needed)
docker run --rm -p 8080:8080 sharukhmukhuram/exammaster-pro:latest
```

Push the image to Docker Hub (after `docker login`):

```bash
docker push sharukhmukhuram/exammaster-pro:latest
```

If you prefer the image to use a different tag or repository, update the
`<image><name>` element in `pom.xml` before running `spring-boot:build-image`.

## CI / GitHub Actions

This repo includes a workflow that builds the image with the Spring Boot
plugin and pushes it to Docker Hub when changes are pushed to `main`.

The workflow requires two repository secrets:
- `DOCKERHUB_USERNAME`
- `DOCKERHUB_TOKEN` (or a Docker Hub access token)

## Environment

The app expects a MySQL database. See `src/main/resources/application.properties` for connection keys.

For local demos you can use the included `docker-compose.yml` at the repo root to start MySQL.

## Troubleshooting
- If `spring-boot:build-image` fails, ensure Docker Desktop is running and the builder can access the daemon.
- To force a specific JVM version for the buildpack, the POM already sets `BP_JVM_VERSION` to `17`.
